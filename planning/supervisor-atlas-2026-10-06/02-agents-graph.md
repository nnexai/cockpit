| G05 | Supervisor/root and run forest | Forest helper stores `{key, depth, run, subagent}`. Runs initially traverse from roots (no parent or parent missing from snapshot), then all runs as fallback, with `visited` preventing duplicate output. A run row key is `run_id`; direct child runs are recursively appended. **The mounted graph does not show every helper row:** the caller filters to `row.run.root_id === root?.run_id` and `row.run.stage !== "closed"` before passing `forest` to the graph. Only non-closed rows for the selected root are eligible; closed roots and closed descendant runs (and their subagents) are excluded from graph display. For eligible rows, layout attaches a run to its parent only if that parent is among visible nodes; absent parent/self-parent becomes a root (`src/app/supervisor/SupervisorView.tsx:16–46,85–104`; `src/app/supervisor/graphLayout.ts:13–21`). |

Subagent node key is `${run_id}:${subagent_id}`; it carries its parent run and nests under same-run parent subagent if that parent exists; orphaned/missing parent subagents become roots relative to run. `seen` prevents duplicate subagents; fallback pass includes cyclic/unreached subagents once. Graph edges are generated among visible row IDs (`src/app/supervisor/SupervisorView.tsx:23–41`; `src/app/supervisor/SupervisorGraph.tsx:34–40`; `src/app/supervisor/graphLayout.ts:16–21,46–63`). |
| G07 | Forest geometry and connections | IDs are sorted lexically for deterministic parent resolution. A detected cycle loses the edge from its lexically smallest cycle member. Iterative traversal avoids recursive layout stack growth. Cards use 180×36 px, 36 px column gap, 8 px row gap, 8 px padding; depth determines horizontal column, descendants occupy contiguous vertical spans, roots stack vertically. SVG Bezier paths connect parent card’s right midpoint to child card’s left midpoint. Missing parents stay roots; no artificial edge is drawn (`src/app/supervisor/graphLayout.ts:6–10,13–21,23–44,46–103`). |
| G08 | Task references | Only non-subagent worker run rows with a task in snapshot board matching the board root ID create task refs. Each ref is keyed `task:${run_id}:${task_id}`. | G09 | Status glyph and provenance | For subagents, raw status is directly `subagent.status`; evidence label is `OMP events`. ## Selection and focus ownership

- Graph selected state is persisted in mutable `scope.selectedRun`, `scope.selectedSubagent`, `scope.selectedTask`; current detail-run highlighting can be independent of keyboard focus. Selection and hover are separate (`SupervisorGraph.tsx:50–57,70–80`; `SupervisorView.tsx:61–73,220–232,303–306`).
- Clicking a node changes detail selection via parent callback; graph Escape clears all three scope selections. Subagent checkbox removal clears subagent selection and schedules parent focus using roving-list `focusRow` (`SupervisorGraph.tsx:70–80,86–94`).
- Roving rows order is forest rows first, then task refs (when actionable), then unmanaged items. Layout geometry is forest-based, but keyboard order is row order, not visual/tree navigation. Shared hook binds Up/Down and Home/End; no graph-specific Left/Right tree navigation is registered here (`SupervisorGraph.tsx:70–72`; `useRovingList.ts:52–60`).
- Pointer parity: run and subagent have click selection and hover; actionable task refs have click-to-select and hover; unmanaged agents open terminal on click but do not have hover callback. Checkbox switches and Board/Agents are native keyboard-operable inputs/buttons. (`SupervisorGraph.tsx:86–95,115,125,132`; `SupervisorView.tsx:303–306`).
- Focus styling globally uses 2px `focus-strong` outline offset -2px for focus-visible on view controls (`supervisor.css:28`). RowSplitter has `:focus` outline suppressed, but focus-visible still selects its pseudo-element accent rule (`supervisor.css:138–140`).

## Empty/error/offline/destructive/undo coverage

- Graph-specific offline handling is observational: no fabricated data is drawn; heading and unmanaged empty copy describe unavailable observation (`SupervisorGraph.tsx:30–32,85,137`). This component does not present a retry control.
- Unknown agent status maps to an unknown glyph while preserving status text/provenance; stale/unverified run status explicitly reads “unobserved” (`SupervisorGraph.tsx:104–118,130–132`).
- Missing parent references do not display an error; layout promotes such nodes to roots. Cycles are repaired deterministically in derived layout without changing snapshot (`graphLayout.ts:13–21,23–44`).
- Graph actions do not confirm or undo: node click selects/toggles detail, switches filter display, resizer changes size, unmanaged click opens terminal. No destructive graph operation appears in these components (`SupervisorGraph.tsx:86–95,115,132`; `RowSplitter.tsx:21–51`).
