How to use

  • Select: click any pane. New panes open beside the selected one.
  • Move: drag a pane header. Drop on the centre to swap; drop near an edge to move it there (half-pane preview); drop on the thin outer rim of the workspace for a full-height/width edge. Esc cancels.
  • Resize: drag a divider (double-click = 50:50, focus + arrow keys nudges).
  • Header buttons: split right / split down (new terminal), zoom, close. Double-click a header also zooms.
  • Files / Review / Browser: one per tab. Opening again focuses it (Files/Review switch source).
  • External terminal: appears at the right edge with width 1/(N+1) of all panes.
  • Closing the last terminal closes every viewer in that tab.
  • Tabs: each has its own arrangement. Viewers cannot move between tabs (no such control).
