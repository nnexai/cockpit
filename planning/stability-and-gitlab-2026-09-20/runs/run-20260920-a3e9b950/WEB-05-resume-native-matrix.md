### Native input qualification and downstream observation

The Native acceptance harness used separated DOM-dispatched PointerEvents for the Region. This is a real WebKit handler/Tauri-store action, **not** compositor-origin or physical pointer proof. WebDriver `/actions` was previously observed to return HTTP 500 unsupported for WebKit; `wayland-info` is installed but `wtype`, `ydotool`, and `dotool` are not. A standalone private Niri probe failed before socket creation with `error initializing the TTY backend` / `Failed to open session: Function not implemented`; no user-compositor injection or package installation was attempted. Native OS keyboard and physical pointer remain unverified.

The later generic routed-pointer/scroll gate timed out after explicit retry. The text was read from `document.querySelector('.browser-toolbar-status')`, so “no eligible agent target is available in this Space” was visibly in BrowserPane's toolbar status; the saved-feedback recovery strip separately still showed Rejected/Retry. This text can be the delivery-refusal status while the next frame is pending and does not by itself prove target loss. **The reported null target/view/document/control/frame are not authoritative:** the harness stored those values in `window.__nativeBrowserTrace`, installed before the initial BrowserPane load, and frontend reload cleared that global. The surviving browser-pane error class and old canvas bitmap likewise do not establish actual stream state. Preceding action was the explicit Retry click, which created rejected operation `browser-feedback-b43443ca-1882-4211-905a-96942ac319e5`; the matrix then saved a distinct editable note/mark before entering the legacy routed-scroll continuation. Recorded Herdr identities are session `native-1fda4706993e`, original Space `w1`, newly created Space `w2`, BrowserPane association `37ff5cf903f9c5e79855b28d`, and capture `space_id=w1`; exact selected tab/pane IDs and a post-retry `session.snapshot` were not captured. The fixture root has been cleaned. Therefore this is an **inconclusive post-retry harness observation**, not evidence of a product workflow/target-reconciliation defect; Main was notified and no source diagnosis or unchanged rerun was made.
